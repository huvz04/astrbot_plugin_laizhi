# 来只图库（AstrBot）

这是基于 [huvz04/LaiZhiChatPlugin](https://github.com/huvz04/LaiZhiChatPlugin)
交互方式重写的 AstrBot 精简版插件。图库按平台和群聊隔离，图片使用 MD5
去重并保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_laizhi/` 下。

## 指令

- `来只 猫猫` 或 `来点 猫猫`：从“猫猫”图库随机发送一张图片。
- `随机来点`、`随机来只`：先按图库权重选择图库，再从该图库随机发送一张近期未出现的图片，并显示来源图库。
- `权重 猫猫 0.5`：将本群“猫猫”图库参与上述随机命令的权重设为 `0.5`，仅管理员可用；
  默认权重为 `1`，设为 `0` 可退出全局随机，但不影响按图库名获取。
- `来只统计`、`来点统计`（也支持空格）：将关键词分布词云、带头像的上传者贡献条形榜、近期热门词词云打包成一条合并转发消息；渲染失败时返回文字。
  每张图仅保留一行功能标题，词云按 `九龙(100)` 格式标注频次；字号和字重随频次变化。词云使用 Python 与 SVG 绘制，无额外词云组件依赖。
  三张图共用一次页面渲染，切图后按实际内容裁去多余留白。
- `抽 3 猫猫`：从“猫猫”图库随机抽取最多 3 张不重复图片，并通过合并转发发送；
  单次默认最多 20 张，可在插件配置中调整。同一群、同一图库会优先抽取近期
  未出现过的图片，图库轮完后才开始新一轮。
- `添加 猫猫`：同条消息附带图片、回复一张图片，或在提示后的 30 秒内发送图片。
- `add 猫猫`：`添加 猫猫` 的英文别名。
- 回复或附带图片发送 `图片信息`、`查图`：查询本群收录位置、添加人 QQ、标记时间（北京时间）、格式、尺寸、文件大小和 MD5；可加图库名，如 `图片信息 猫猫`。
- 回复图片并发送 `删除 图库名`：从指定图库删除该图片，仅管理员可用。
- `#清理 图库名`：删除整个图库，仅管理员可用。

图库名只允许中英文和数字，最长 30 个字符。支持 JPEG、PNG、GIF 和 WebP，
单张图片不能超过 20 MiB。
“统计”是保留词，禁止添加同名图库，不参与全局随机或词频统计；已有同名图库的数据不会删除。

统计仅使用当前群的数据。关键词即图库名；全部关键词按当前图库图片数标注，近期热门词按近 7 天的成功调用次数标注（一次批量抽取计一次调用），可通过 `overview_recent_days` 调整天数。
贡献榜按成功新增图片数排名，重复上传不计数；QQ 头像缓存一天，获取失败时使用名字占位。
词云默认展示频次最高的 50 个关键词，可通过 `overview_max_galleries` 调整至 1–200；贡献榜默认前 10 名，可通过 `overview_top_users` 调整至 1–20。
旧命令 `预览全部`、`图库统计` 已由 `来只统计`、`来点统计` 替代。

回复图片使用 `添加 图库名` 时，消息中的 `At` 会被忽略。添加成功后，机器人会
复读被添加的图片，并回复“已添加到图库名”。

统计数据保存在插件数据目录的 `gallery_stats.db`。贡献与调用从升级后开始记录；
历史图片仍会计入当前图库数量，但不会猜测历史添加者。

图片信息使用真实的成功添加记录；找不到添加人或标记时间时显示“未知”，不会用查询者或文件修改时间代替。重复上传不会覆盖原添加人或时间；删除、清空后重新添加则记录新一轮来源。

添加、抽图、统计、查图时会自动核对文件与索引，移除已丢失文件的缓存；空文件、损坏文件和同一图库内多余的重复副本会移入 `data/plugin_data/astrbot_plugin_laizhi/_quarantine/平台/群号/图库名/`，可手动恢复，不会直接销毁。正常有效的重复图片仍会提示已收录，累计贡献和调用历史会保留。
